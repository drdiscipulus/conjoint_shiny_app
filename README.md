# Conjoint App

## The purpose of this conjoint app is twofold:

### 1. Provide researchers with a factorial design generator

* Especially fractional factorial designs are often used in conjoint studies to reduce/minimize the number of decision profiles
* However, these designs are not always easy to come by and researchers tend to rely on old ortho-plan publications
* For this purpose, we bundle two R packages to generate factorial designs into an accessible user interface

### 2. We bundle our proposed workflow for evaluating response consistency in conjoint studies into an easy to use app
* The corresponding paper: Test-Retest Reliability in Metric Conjoint Experiments: A New Workflow to Evaluate Confidence in Model Results
* In this paper, we outline and show an analytical workflow to help researchers better probe threats to response consistency and to evaluate — and communicate — confidence in statistical models using conjoint data
